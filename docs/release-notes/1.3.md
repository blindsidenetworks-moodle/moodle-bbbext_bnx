# BNX 1.3

Released November 12, 2026.

BNX 1.3 is the stable release for Moodle 5.3. It is version `2026110503` and
supersedes the 1.3 alpha and beta releases. Moodle 6.0 remains under
development and is not declared as a compatible stable-release target.

## Feature controls and core delegation

Administrators can independently enable or disable BNX Waiting Room, Lock
Settings, Early Access, multiple-presentation management, email reminders, and
session-logo display. Each feature is enabled by default. When a BNX override
is disabled, the parent BigBlueButton activity provides its corresponding core
behaviour where one exists. Guest access is fully owned by the parent activity.

## Presentations

Teachers can attach multiple presentation files to an activity. At meeting
creation, BNX supplies BigBlueButton with short-lived, activity-bound URLs to
retrieve those files. Presentation upload validation and the non-interactive
presentation service account have been hardened for this stable release.

## Security and reliability

BNX 1.3 includes the completed remediation of the MDLSHIELD 1.3 review:

- secure reminder unsubscribe and subscription handling;
- safe output and presentation file URL handling;
- presentation upload type and limit enforcement;
- correct teacher group resolution and legacy reminder preference migration;
- cleanup limited to BNX-owned lifecycle data; and
- non-interactive presentation service accounts with conservative legacy
  migration.

See the preceding alpha and beta release notes for the detailed development
history.
