# BNX 1.3 Alpha 1

Released September 17, 2026.

BNX 1.3 alpha integrates Early Access and pre-uploaded presentations into the
`bbbext_bnx` subplugin. It requires Moodle 5.3 (Build 20260714) or later and
remains an alpha release while formal security/compliance review is pending.

## Merged features

- **Early Access:** A new `bbbext/bnx:earlyjoinaccess` capability lets
  authorised teachers join an activity before its opening time when Early
  Access is enabled. Students cannot infer a running meeting before the room is
  open.
- **Presentations:** Activity editors can add multiple presentation files to
  the BNX activity form. BNX persists the files and metadata, displays them in
  meeting information, includes them in BigBlueButton create requests, and
  preserves them through course backup and restore.
- **Secure file delivery:** BigBlueButton presentation URLs use the
  `bbbext_bnx_get_file` web service with a short-lived token, an activity
  binding, and a bounded use count. The service rejects invalid, expired,
  exhausted, replayed, and cross-activity requests.

## Sidecar and migration decision

This is a clean-install release for the merged functionality. The former
`bbbext_bnx_earlyaccess` and `bbbext_bnx_preuploads` sidecars were never
shipped, so BNX 1.3 does not migrate their settings, records, or files. Do not
enable either sidecar with BNX 1.3.

## Compatibility constraint

BNX retains its guest-link lookup shim because the parent module does not yet
expose a supported public guest-link lookup API. MDL-85873 is included in the
Moodle 5.3 baseline, but it only corrects guest-name handling and does not
provide this API. The shim will be re-evaluated after the relevant Moodle core
API is available.

## Validation status

- Targeted PHPUnit coverage validates Early Access authorization, presentation
  form/lifecycle behavior, token-protected delivery, and presentation
  backup/restore.
- The presentation upload Behat scenario is included and parses successfully.
  Browser execution requires a Selenium or WebDriver server on `localhost:4444`.
