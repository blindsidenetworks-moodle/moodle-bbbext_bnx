# BNX 1.3 Beta 3

Released November 10, 2026.

BNX 1.3 Beta 3 is version `2026110502`. It supports Moodle 5.3 through Moodle
6.0 and remains a beta release.

## Presentation service account hardening

New BNX presentation service accounts use Moodle's non-interactive
`webservice` authentication and an `.invalid` email address. The beta.3 upgrade
migrates only accounts that BNX previously marked as its own and whose legacy
identity remains unchanged. Accounts that administrators may have created or
repurposed are not changed.
