# BNX 1.3 Beta 2

Released November 5, 2026.

BNX 1.3 Beta 2 is version `2026110501`. It supports Moodle 5.3 through Moodle
6.0 and remains a beta release.

## Feature enablement

Administrators can independently enable or disable every BNX feature area:

- Waiting Room
- Lock Settings
- Early Access
- Multiple presentations
- Email reminders
- Session logo display

All features are enabled by default. When Waiting Room, Lock Settings, or
multiple presentations are disabled, the corresponding parent-module controls
remain available. Disabling Early Access, reminders, or logo display suppresses
that BNX behaviour. Dependent settings are disabled in the administration UI
when their feature is disabled.

## Guest access

The remaining BNX guest-access rendering has been removed. The parent
`mod_bigbluebuttonbn` module now owns the guest-access UI and flow end to end.
BNX guest reminders remain available through the separate reminder callback and
tasks.
